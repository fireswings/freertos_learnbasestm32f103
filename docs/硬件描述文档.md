文档说明

本文档基于用户提供的4张引脚定义图片整理，涵盖引脚编号、GPIO映射、功能资源、复用状态、连接关系等关键信息，字段说明如下：  
• 引脚编号：开发板上物理引脚序号（唯一标识）  

• GPIO：对应STM32的GPIO端口（仅PA/PB系列在第1张图中明确，其余留空）  

• 引脚名称：引脚功能别名（如IIC_SCL、BEEP等）  

• 功能缩写：功能简称（如FSMC_D2、1WIRE_DQ等）  

• 连接资源/功能：引脚核心功能（如USART2_TX、LCD_BL等）  

• 是否独立(Y/N)：引脚是否为完全独立IO（来自第1张图“完全独立”列，Y=独立，N=复用/绑定特殊功能）  

• 是否复用(Y/N)：引脚是否复用其他外设功能（来自第2张图“是否复用”列）  

• 是否使用(Y/N)：引脚是否被使用（来自第4张图“是否使用”列，未提及则为“-”）  

• 功能描述/连接关系说明：详细连接对象或使用注意事项  

• 备注：特殊说明（如JTAG接口禁用提示、晶振占用等）

核心硬件模块引脚汇总

1. 仿真接口（JTAG/SWD）

• PA13(JTMS/SWDIO)、PA14(JTCK/SWDCLK)、PA15(JTDI)、PB3(JTDO)、PB4(JTRST)：复用为JTAG/SWD仿真接口，做普通IO需先禁用JTAG&SWD。  

2. 通信接口

• USART1：PA9(TX)、PA10(RX)  

• USART2：PA2(TX/485_RX)、PA3(RX/485_TX)  

• USB：PA11(D-)、PA12(D+)  

• CAN：PA11(CRX)、PA12(CTX)（复用USB引脚，通过跳线帽切换是用USB还是CAN）  

• RS485：PD7(RS485_RE控制)、PA2/PA3(USART2复用)  

• IIC：PB6(SCL)、PB7(SDA)（24C02）；PD3(SCL)、PG13(SDA)（OLED/CAMERA）  

3. 存储接口

• SD卡：PC8(D0)、PC9(D1)、PC10(D2)、PC11(D3)、PC12(SCK)、PD2(CMD)  

• SPI Flash：PB12(F_CS)、PB13(SCK)、PB14(MISO)、PB15(MOSI)（25Q128）  

4. 显示与摄像头

• TFTLCD：FSMC总线（PD0-D2/D3/D4/D5/D6/D14/D15、PE7-D15、PG0(A10)、PG12(NE4)等）  

• OLED/CAMERA：PC0-7(D0-D7)、PD3(SCL)、PD6(WRST)、PG13(SDA)、PG14(RRST)、PG15(OE)  

5. 外设控制

• LED：PE5(LED1绿)、PB5(LED0)  

• 按键：PE3(KEY1)、PE4(KEY0)、PA0(KEY_UP)  

• 蜂鸣器：PB8(BEEP)  

• 红外接收：PB9(REMOTE_IN)  

• 单总线：PG11(1WIRE_DQ，DHT11/DS18B20)
