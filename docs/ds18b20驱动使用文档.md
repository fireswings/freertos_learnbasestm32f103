# ds18b20 DS18B20 温度传感器驱动使用文档

## 概述
基于 1-Wire 总线的 DS18B20 数字温度传感器驱动，12-bit 分辨率（精度 0.0625°C）。

## 硬件
| 信号 | 引脚 |
|------|------|
| DQ | PG11 (共享 1-Wire 总线) |

## API

```c
#include "ds18b20.h"

uint8_t DS18B20_Init(void);              // 初始化传感器，返回 1=在线, 0=离线
void    DS18B20_StartConversion(void);    // 启动温度转换
float   DS18B20_ReadTemp(void);           // 读取温度（需在 StartConversion 后 ≥750ms 调用）
```

## 参数说明
- `DS18B20_Init()`：内部调用 `OW_Init()` 和 `OW_Reset()`，返回是否检测到设备
- `DS18B20_StartConversion()`：发送 Skip ROM + Convert T 命令
- `DS18B20_ReadTemp()`：发送 Skip ROM + Read Scratchpad 命令，读取前两个字节并计算温度
- 转换时间：12-bit 分辨率需要 ≤750ms

## 使用示例
```c
if (DS18B20_Init())
{
    printf("DS18B20 online\r\n");
    DS18B20_StartConversion();
    osDelay(750);                           // 等待转换完成
    float temp = DS18B20_ReadTemp();
    printf("Temp: %.1f C\r\n", temp);       // Temp: 25.4 C
}
else
{
    printf("DS18B20 not found\r\n");
}
```

## 注意事项
- 依赖 `onewire.h` 驱动，需先编译链接 `onewire.c`
- `ReadTemp` 仅在 `StartConversion` 后 ≥750ms 调用才有有效数据
- 温度计算公式：`raw = (msb << 8) | lsb; temp = raw * 0.0625`
